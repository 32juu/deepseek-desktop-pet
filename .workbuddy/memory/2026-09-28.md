- 做法：**像素级擦除** assistant.png 自带文案（原始图片备份 `assets/sprites/assistant-orig.png`）。
  - 文案位置（399x336 原图）：第二行 x≈96..300、y≈269..283（行 270-283 深墨纳 #081a40）；左侧图标在 x 39..85，右侧图标 x 320..355，都已避开。
