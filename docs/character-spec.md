## 2. 核心状态（13）

| # | 状态 | 标识 | 表现 | 触发场景 |
|---|---|---|---|---|
| 1 | 待机 | `idle` | 轻微上下浮动，尾巴摆动，偶尔眨眼，观察周围 | 默认常驻 |
| 2 | 眨眼 | `blink` | 随机眨眼，增加生动感 | 待机中随机 |
| 3 | 睡眠 | `sleep` | 闭眼休息，呼吸轻微，鱼尾蜷起，头顶 Zzz | 长时间无操作 |
| 4 | 开心 | `happy` | 眼睛弯曲，嘴巴张开，双手握拳，尾巴翘起 | 完成学习任务 |
| 5 | 思考 | `thinking` | 托下巴或双手抱胸，眼神向上，头顶问号 | 答疑题目 |
| 6 | 对话 | `talking` | 嘴巴微张，身体前倾，手部摆动，配合对话气泡 | AI 对话 |
| 7 | 加载 | `loading` | 抱住加载球或看着转圈图标 | AI 处理中 |
| 8 | 学习中 | `learning` | 专注看书或屏幕，安静认真，尾巴缓慢摆动，气泡显示计时/科目 | 学习开始后 |
| 9 | 深度学习 | `thinking_hard` | 眉头微皱，头顶显示知识点/代码（如 Java、MySQL、Redis、Spring） | 攻坚难题 |
| 10 | 完成 | `success` | 双手举起，眼睛星星，庆祝学习成果 | 学习完成 |
| 11 | 关心提醒 | `concern` | 歪头、眉头微皱，语气温和，气泡"休息一下吧~" | 长时间未学习 |
| 12 | 小生气 | `angry` | 脸鼓起，叉腰，鱼尾甩动（依然可爱） | 答错题目 |
| 13 | 庆祝 | `celebration` | 跳跃、挥手、烟花/星星特效 | 重大成就或连续学习 |

## 3. 微动效细节

眨眼 · 头发摆动 · 鱼尾摆动 · 呼吸动效 · 耳鳍抖动。

所有状态均基于同一角色基准形象，不允许出现形象漂移。

## 4. 表情集（8）

开心、害羞、生气、惊讶、难过、困惑、得意、无奈。
表情可与状态叠加（如 `learning` + 困惑）。

## 5. 动作触发规则（示例）

| 事件 | → 状态 |
|---|---|
| 学习开始 | 学习中 |
| 学习完成 | 开心 / 庆祝 |
| 长时间未学习 | 关心提醒 |
| AI 处理中 | 加载 |
| 答对题目 | 开心 |
| 答错题目 | 思考 / 鼓励 |
| 连续学习 | 庆祝 |

## 6. 实现注意

- 状态机需要支持：单次播放（`blink`）与持续播放（`idle` / `learning`）两类。
- 状态优先级：系统态（`loading` / `talking`）> 事件态（`success` / `angry`）> 常态（`idle` / `sleep`）。
- 提醒类状态（`concern`）必须遵守"少打扰"原则：可关闭、可调频率。
